# 기술 스택과 아키텍처 제약

Oct 5, 2026 · @DevYoung

두 군이 같은 기술적 제약 위에서 구현해야, 결과 차이가 가드레일 때문인지 기술 선택 때문인지가 섞이지 않는다. 노출 계약은 [docs/common/repository/](../repository/), 컴포넌트 규칙은 [ui/components.md](../ui/components.md)를 따른다.

## 기술 스택

| 항목 | 도구 |
| --- | --- |
| 프레임워크 | Vite + React |
| 라우팅 | React Router |
| 언어 | TypeScript |
| 스타일링 | Tailwind CSS |
| 전역 상태 관리 | React Context |
| 테스트 | Vitest, React Testing Library, Playwright |
| 린트/포맷 | ESLint, Prettier |
