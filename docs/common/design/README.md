# 설계

Oct 14, 2026 · @DevYoung

어떻게 만드는지 다루는 디렉토리다 — 기술 스택, 코드 구조, 데이터 계약, UI 구현 규칙. 무엇을 만드는지는 [planning/](../planning/)을 따른다.

## 목차

- [architecture/](./architecture/) — 기술 스택, 디렉토리 구조, 데이터 흐름
- [repository/](./repository/) — 타입, Repository 메서드, 저장 키, 에러 코드, 시드 데이터
- [domain/](./domain/) — 순수 규칙 함수, Result, 상태 전이, 쿠폰 실패 코드
- [context/](./context/) — 전역 상태(지갑), 주문 액션과 호출 흐름
- [ui/components.md](./ui/components.md) — 컴포넌트 제작 규칙
