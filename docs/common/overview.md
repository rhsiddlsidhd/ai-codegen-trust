# 프로젝트 개요

Oct 7, 2026 · @DevYoung

이 문서는 baseline/guarded 두 프로젝트가 똑같이 참조하는 단일 기획 문서(PRD 역할)다. 여기 없는 내용은 각자의 문서를 따른다 — 기술 제약은 [tech-stack.md](./architecture/tech-stack.md), 화면 레이아웃은 [ui/wireframe.md](./ui/wireframe.md), 노출 계약은 [docs/common/repository/](./repository/). 실험 자체(가드레일 비교)의 상세 설계는 [README.md](../../README.md)를 따른다.

## 핵심 기능

| 기능 | 설명 | 관련 라우트 |
| --- | --- | --- |
| 상품 목록/재고 조회 | 상품 title/des와 현재 재고를 보여준다 | /cart |
| 수량 조절 | 품목별 주문 수량을 1~99로 조절한다 | /cart |
| 주문 생성 | 장바구니 품목으로 주문을 만들고 재고를 차감한다 | /cart |
| 쿠폰 분류/선택 | 품목 라인금액 또는 주문 전체금액 기준으로 사용 가능/불가 쿠폰을 나누고, 1장만 선택·교체한다 | /payment/:id |
| 결제금액 계산 | 쿠폰 적용 후 할인액과 최종 결제금액을 계산한다 | /payment/:id |
| 결제 시도 | 지갑 현금과 결제금액을 비교해 성공/실패를 결정한다 | /payment/:id |
| 주문 취소 | CREATED 상태 주문을 취소하고 재고를 복원한다 | /payment/:id |
| 영수증 조회 | 주문 상태, 품목, 금액, 실패 이유를 보여준다 | /orders/:id |
| 전체 환불 | PAID 주문을 환불하고 재고·지갑 현금을 복원한다 | /orders/:id |
| 보유 현금 표시 | 지갑 cash를 전역 레이아웃에서 보여준다 | 전역 |
| 에러 안내 | 규칙 위반 시 에러 코드를 전역 토스트로 보여준다 | 전역 |
| 주문 없음 가드 | 존재하지 않거나 라우트 상태가 안 맞는 주문 접근 시 404 화면을 보여준다 | /payment/:id, /orders/:id |

## MVP 제외 사항

| 항목 | 제외 이유 |
| --- | --- |
| 배송 상태 | 결제 이후 흐름 밖 — 이 실험 소재는 주문~환불 상태 머신까지만 다룬다 |
| 부분 환불 | 환불은 전체 환불 하나만 정의돼 있다 |
| 회원 계정 | 로그인/계정 식별 없이 sessionStorage 하나로 세션 상태만 관리한다(architecture/tech-stack.md) |
| 실제 결제 연동 | 결제는 모의 — 지갑 현금과 결제금액 비교만으로 성공/실패를 결정한다 |
| 다중 탭 시나리오 | 저장소가 sessionStorage(탭 단위)라 여러 탭 동시 사용은 다루지 않는다 |
| 쿠폰 발행 | 쿠폰은 시드로 고정된 4종(C1~C4)뿐, 새로 발행하는 기능이 없다 |
| 쿠폰 코드 직접 입력 | 목록에서 선택만 가능하고 코드를 타이핑해 입력하는 UI는 없다 |
| 수량 조건 쿠폰 | 시드 4종(C1~C4) 안에 없는 쿠폰 종류 |
| 카테고리 쿠폰 | 시드 4종(C1~C4) 안에 없는 쿠폰 종류 |
| 결제 수단 선택 UI | 결제 수단은 지갑 현금 하나뿐, `pay-button` 단일 버튼이라 선택 UI가 없다 |
| 지갑 충전 | 지갑 cash는 세션당 고정값이고 충전 기능이 없다 |
