## UI 라우트

| 라우트 | 내용 |
| --- | --- |
| `/cart` | 상품 선택, 수량 조절. 쿠폰·결제는 여기서 안 함 |
| `/payment/:id` | 결제 대기 주문의 쿠폰 선택 + 결제/취소 |
| `/orders/:id` | 결과(결제 완료/결제 실패/환불 완료) 영수증, 결제 완료일 때만 환불 |

## 전역 레이아웃

보유 현금은 특정 라우트 요소가 아니라 공통 레이아웃(헤더)에 박아서 `/cart`, `/payment/:id`, `/orders/:id` 어디서든 보인다. 헤더 우측에 "[보유 현금 아이콘] 금액" 형태로 둔다.

```
+--------------------------------------------------+
|  (헤더)                   [아이콘] [보유 현금]   |
+--------------------------------------------------+
|  (라우트별 내용)                                 |
+--------------------------------------------------+
```

## /cart

```
+--------------------------------------------------+
|  장바구니                                        |
+--------------------------------------------------+
|  [선택 체크박스] [상품명]                        |
|  [상품 설명]                                     |
|    수량 [−] [수량 입력] [+]                      |
+--------------------------------------------------+
|  [선택 체크박스] [상품명]                        |
|  [상품 설명]                                     |
|    수량 [−] [수량 입력] [+]                      |
+--------------------------------------------------+
|                          [주문하기 버튼]         |
+--------------------------------------------------+
```

/cart에 들어올 때마다 모든 상품은 체크 해제, 수량 1로 시작한다(이전 선택을 기억하지 않는다). 체크한 상품만 주문에 들어간다. 버튼 문구는 "주문하기"다([user-flow.md](./user-flow.md)와 같은 이름).

- [−]는 수량 1, [+]는 수량 99에서 비활성이다
- 입력칸에는 숫자만 입력된다. 0·100 같은 범위 밖 값이나 빈 칸은 그대로 두고, "주문하기"를 누를 때 오류 안내 토스트로 알린다
- 체크하지 않은 상품의 수량은 검사하지 않는다

## /payment/:id

```
+--------------------------------------------------+
|  결제        주문 id: [주문 id]                  |
+--------------------------------------------------+
|  선택한 상품                                     |
|  상품명 × 수량 (반복)                            |
+--------------------------------------------------+
|  주문금액: [금액]                                |
+--------------------------------------------------+
|  쿠폰                                            |
|  [사용 가능 탭] | [사용 불가 탭]                 |
|  --------------------------------------------    |
|  [쿠폰 코드 · 혜택]  ... (반복)                  |
+--------------------------------------------------+
|  할인액: [금액]                                  |
|  결제금액: [금액]                                |
+--------------------------------------------------+
|           [취소 버튼]        [결제 버튼]         |
+--------------------------------------------------+
```

사용 불가 탭의 쿠폰 항목은 표시만 하고 선택할 수 없다(비활성). 불가 사유는 표시하지 않는다. 사용 가능 탭의 항목은 누르면 선택(다른 쿠폰이 선택돼 있으면 교체)되고, 선택된 항목을 다시 누르면 해제된다(토글).

- 처음 들어오면 사용 가능 탭이 열려 있다
- 쿠폰 항목은 쿠폰 코드와 혜택 문구(아래 [표기 형식](#표기-형식))를 보여준다. 선택된 항목은 강조한다
- 탭이 비면 사용 가능 탭은 "사용할 수 있는 쿠폰이 없습니다.", 사용 불가 탭은 "사용할 수 없는 쿠폰이 없습니다."를 보여준다

```
|  결제금액: [금액]                                |

+--------------------------------------------------+
|  [환불 버튼]                   (결제 완료일 때만)|
+--------------------------------------------------+
|                          [장바구니로 버튼]       |
+--------------------------------------------------+
```

## 주문 없음(404)

`/payment/:id`, `/orders/:id`에서 주문이 없거나 그 라우트에 맞는 상태가 아니면, 같은 URL 자리에서 이 화면을 보여준다(자동 리다이렉트 아님). 두 경우(주문 없음, 상태 불일치)를 같은 문구로 보여준다. 가드 규칙은 [user-flow.md](./user-flow.md#가드-규칙)를 따른다.

```
+--------------------------------------------------+
|  주문을 찾을 수 없습니다.                        |
|  주문이 없거나 이 화면에서 볼 수 없는 주문입니다.|
+--------------------------------------------------+
|                          [장바구니로 버튼]       |
+--------------------------------------------------+
```

## 전역 토스트

오류 메시지는 라우트 안이 아니라 전역 토스트로 뜬다. 세 라우트 어디서든 같은 토스트 레이어를 쓴다. 표시 내용은 [policy.md](./policy.md#오류-안내)의 안내 문구이고, 5초 후 자동으로 사라진다. 쿠폰 관련 오류는 띄우지 않는다.

## 표기 형식

| 대상 | 형식 | 예 |
| --- | --- | --- |
| 금액(보유 현금, 주문금액, 결제금액) | ₩ + 천 단위 콤마 | `₩8,000`, `₩0` |
| 할인액 | 앞에 `-`(일반 하이픈). 0이면 부호 없음 | `-₩3,000`, `₩0` |
| 쿠폰 혜택(정액) | 금액 + "할인" | `₩5,000 할인` |
| 쿠폰 혜택(정률) | 비율 + "할인", 상한이 있으면 "(최대 금액)" | `20% 할인 (최대 ₩3,000)`, `10% 할인` |
