## 용어

| 용어 | 뜻 |
| --- | --- |
| 라인 금액 | 품목 하나의 단가 × 수량 |
| 주문금액 | 모든 라인 금액의 합(할인 전) |
| 결제금액 | 주문금액 - 할인액 |
| 할인액 | 쿠폰으로 깎이는 금액 |
| 할인 기준 금액 | 쿠폰 종류별로 할인을 계산하는 기준 금액([쿠폰 종류](#쿠폰-종류)) |

## 주문 수량

품목별 주문 수량은 1~99다.

## 쿠폰

주문 하나에 쿠폰은 최대 1장만 적용한다. 쿠폰은 써도 소모되지 않는다.

### 쿠폰 종류

| 종류 | 사용 조건 | 할인 기준 금액 |
| --- | --- | --- |
| 대상 상품 쿠폰 | 주문에 대상 상품이 있다 | 대상 상품의 라인 금액 |
| 고액 라인 쿠폰 | 라인 금액이 기준 이상인 품목이 있다 | 기준 이상인 라인 금액의 합 |
| 최소 주문금액 쿠폰 | 주문금액이 기준 이상이다 | 주문금액 |
| 전체 주문 쿠폰 | 조건 없음 | 주문금액 |

### 할인 방식

- 정액: 정해진 금액을 할인하되 할인 기준 금액을 넘지 않는다. 그래서 결제금액은 0 미만이 되지 않는다
- 정률: 할인 기준 금액에 비율을 곱하고 원 미만은 버린다. 상한이 있으면 그 값을 넘지 않는다

## 지갑

보유 현금은 세션 시작 시 정해진 값에서 출발하고, 충전 기능은 없다.

## 주문 상태

| 상태 | 뜻 | 할 수 있는 동작 |
| --- | --- | --- |
| 결제 대기 | 주문을 만들고 아직 결제하지 않음 | 쿠폰 선택·교체·해제, 결제, 취소 |
| 결제 완료 | 결제 성공 | 환불 |
| 결제 실패 | 보유 현금 부족으로 결제 실패 | 없음(종료) |
| 주문 취소 | 결제 전에 취소 | 없음(종료) |
| 환불 완료 | 결제 완료 주문을 전체 환불 | 없음(종료) |

- 결제는 보유 현금이 결제금액 이상이면 결제 완료, 아니면 결제 실패다
- 결제 실패는 다시 결제할 수 없고, 결제 완료는 취소할 수 없다(환불만 가능)
- 표에 없는 동작은 할 수 없다. 안내 문구는 [오류 안내](#오류-안내)의 "현재 주문 상태에서 할 수 없는 동작"을 따른다

## 재고 차감/복원 시점

| 시점 | 재고 변화 |
| --- | --- |
| 주문 생성 | 품목 수량만큼 차감 |
| 결제 실패 | 품목 수량만큼 복원. 결제 실패는 다시 결제할 수 없는 종료 상태라, 복원하지 않으면 생성 때 차감한 재고가 묶인 채 남는다 |
| 취소 | 품목 수량만큼 복원 |
| 환불 | 품목 수량만큼 복원 |

## 현금 차감/복원 시점

| 시점 | 현금 변화 |
| --- | --- |
| 결제 성공 | 결제금액만큼 차감 |
| 결제 실패 | 변화 없음(차감한 적 없음) |
| 취소 | 변화 없음 |
| 환불 | 차감했던 결제금액만큼 복원 |

## 오류 안내

규칙 위반 시 사용자에게 보여줄 안내 문구다.

| 상황 | 안내 문구 |
| --- | --- |
| 체크한 품목 없이 주문 | 주문할 상품을 선택해 주세요. |
| 수량이 1~99 밖 | 수량은 1개 이상 99개 이하로 입력해 주세요. |
| 재고보다 많은 수량 주문 | 재고가 부족합니다. |
| 사용 조건을 충족하지 않는 쿠폰 적용 | 사용할 수 없는 쿠폰입니다. |
| 최소 주문금액에 못 미치는 쿠폰 적용 | 최소 주문금액을 충족하지 않는 쿠폰입니다. |
| 현재 주문 상태에서 할 수 없는 동작 | 지금은 처리할 수 없는 요청입니다. |

- 쿠폰 관련 두 상황은 안내하지 않는다. 사용 불가 쿠폰은 선택 자체가 막혀 있어서 정상 조작으로는 생기지 않고, 생기더라도 기존 선택을 그대로 유지한다
- 사용 불가 쿠폰에는 불가 사유를 표시하지 않는다

## 결제 실패 사유

결제 실패 사유는 보유 현금 부족 하나다. 영수증에 "현금이 부족합니다."로 표시한다.
