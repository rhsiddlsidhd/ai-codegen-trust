# 프로젝트 개요

Oct 7, 2026 · @DevYoung

이 문서는 unguarded/guarded 두 프로젝트가 똑같이 참조하는 단일 기획 문서(PRD 역할)다. 여기 없는 내용은 각자의 문서를 따른다 — 비즈니스 규칙은 [policy.md](./policy.md), 화면 흐름은 [user-flow.md](./user-flow.md), 화면 레이아웃은 [wireframe.md](./wireframe.md). 실험 자체(가드레일 비교)의 상세 설계는 [README.md](../../../README.md)를 따른다.

## 핵심 기능

| 기능 | 설명 | 관련 라우트 |
| --- | --- | --- |
| 상품 목록 조회 | 상품명·설명을 보여준다. 재고는 표시하지 않는다 | /cart |
| 수량 조절 | 품목별 주문 수량을 1~99로 조절한다 | /cart |
| 주문 생성 | 체크한 품목으로 주문을 만들고 재고를 차감한다 | /cart |
| 쿠폰 분류/선택 | 쿠폰 종류별 사용 조건([policy.md](./policy.md#쿠폰-종류))에 따라 사용 가능/불가 쿠폰을 나누고, 사용 가능 쿠폰 1장만 선택·교체·해제한다. 사용 불가 쿠폰은 선택할 수 없다 | /payment/:id |
| 결제금액 계산 | 쿠폰 적용 후 할인액과 결제금액을 계산한다 | /payment/:id |
| 결제 시도 | 지갑 현금과 결제금액을 비교해 성공/실패를 결정한다 | /payment/:id |
| 주문 취소 | 결제 대기 주문을 취소하고 재고를 복원한다 | /payment/:id |
| 영수증 조회 | 주문 상태, 품목, 금액(주문금액·할인액·결제금액), 실패 이유를 보여준다 | /orders/:id |
| 전체 환불 | 결제 완료 주문을 환불하고 재고·보유 현금을 복원한다 | /orders/:id |
| 보유 현금 표시 | 보유 현금을 모든 화면 공통 헤더에서 보여준다 | 전역 |
| 오류 안내 | 규칙 위반 시 안내 문구([policy.md](./policy.md#오류-안내))를 전역 토스트로 보여준다 | 전역 |
| 주문 없음 가드 | 존재하지 않거나 라우트 상태가 안 맞는 주문 접근 시 404 화면을 보여준다 | /payment/:id, /orders/:id |

## MVP 제외 사항

| 항목 | 제외 이유 |
| --- | --- |
| 배송 상태 | 결제 이후 흐름 밖 — 이 실험 소재는 주문~환불 상태 머신까지만 다룬다 |
| 부분 환불 | 환불은 전체 환불 하나만 정의돼 있다 |
| 회원 계정 | 로그인/계정 식별 없이, 데이터는 브라우저 탭(세션) 단위로만 유지된다 |
| 실제 결제 연동 | 결제는 모의 — 지갑 현금과 결제금액 비교만으로 성공/실패를 결정한다 |
| 다중 탭 시나리오 | 데이터가 탭 단위로만 유지되므로 여러 탭 동시 사용은 다루지 않는다 |
| 쿠폰 발행 | 쿠폰은 미리 정해진 목록뿐, 새로 발행하는 기능이 없다 |
| 쿠폰 코드 직접 입력 | 목록에서 선택만 가능하고 코드를 타이핑해 입력하는 UI는 없다 |
| 수량 조건 쿠폰 | 쿠폰 종류 4가지([policy.md](./policy.md#쿠폰-종류)) 안에 없다 |
| 카테고리 쿠폰 | 쿠폰 종류 4가지([policy.md](./policy.md#쿠폰-종류)) 안에 없다 |
| 결제 수단 선택 UI | 결제 수단은 지갑 현금 하나뿐, 결제 버튼 하나라 선택 UI가 없다 |
| 지갑 충전 | 보유 현금은 정해진 값에서 출발하고 충전 기능이 없다 |
